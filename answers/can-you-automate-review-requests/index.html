Can you automate review requests?

Ascent Vision · Published October 30, 2026

Yes. Send the same request to every customer at the same point, such as when the job is done or the invoice is paid, with at most one reminder, by text only with the person's consent and with no reward of any kind. Be wary of tools that ask only the customers expected to be happy: Google's policy lists selectively soliciting positive reviews as not allowed, and the FTC says the practice could violate the FTC Act. This is a plain summary, not legal advice.

What is fine to automate

The related answer on how to get more reviews the right way covers how to ask. This page is about what changes when software does the asking; the settings below are general advice.

The trap some tools offer

Some review tools can be set to open with a satisfaction question and send only the happy customers on to the review site. Google's policy and the FTC's guidance on that practice are covered in the related answer on discounts and gifts for reviews.

This is a plain summary, not legal advice. As general advice, treat any setup that routes customers by their expected rating the same way. If a job has an open problem, a short delay to the timing for that job, while it is fixed, can be reasonable, as long as it is never used as a filter and the same request still goes out afterward.

What to check in a review tool

Set the tool up so that no customer is treated differently by mood.

TriggerOne point, the same for every customer: the job is marked done, or the invoice is paidRequests sent at different points for different customers
